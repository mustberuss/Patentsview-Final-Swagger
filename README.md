# Patentsview API Swagger-UI

The Patentsview API team has shutdown both versions of their API and removed their [Swagger UI page](https://search.patentsview.org/swagger-ui) for the later version of their API.  This Swagger UI page uses what was the final version of their Swagger object for the later version of their API.

The later version of the API is supposed to appear on the USPTO's Open Data Portal as mentioned [here](https://data.uspto.gov/support/transition-guide/patentsview), but it hasn't yet.  Note that the new version of the API is available from https://patentref.io/, in beta with usage restrictions.
